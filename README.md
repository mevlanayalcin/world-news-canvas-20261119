Nine verified stories span six regions and nine beats: the first Trump–Xi–Putin trilateral in Shenzhen, Anthropic's $1.5tn Nasdaq listing, Voyager 1 at one light-day, COP31's fossil-fuel draft in Antalya, the ICJ's Rohingya genocide ruling, Iran strike options and Israel's Gaza raid, Africa's cyber surge, GTA VI's worldwide launch, and the IMF's 4.7% inflation warning. The front page is hand-built with inline SVG art; `main.py` validates and atomically copies the committed `entry.png` to the requested output directory.
